# BI-32 — базовый каталог бизнес-KPI

Модуль `db/business_kpis.py` создаёт **предложения**, а не автоматически утверждённые бизнес-метрики. Использует только известные названия полей из технического каталога и проверяет наличие колонок и допустимость приведений.

```bash
python db/business_kpis.py --catalog data/schema-catalog.json --output data/kpi-definitions.json
python -m unittest discover -s db -p 'test_*.py'
```

Показатели: количество строк продаж, количество строк типа «Продажа», сумма с учётом скидки, количество обращений, среднее время закрытия, расходы на рекламу, клики, CTR. Каждая запись содержит формулу для уже типизированной таблицы `t`, единицу, необходимые колонки, статус `proposed` / `unavailable`, предупреждения и флаг `requires_business_approval=true`.

**Не считать этот модуль готовым генератором финансовой отчётности**: возвраты/знак, правила выручки, обработка незакрытых обращений и дублей должны быть согласованы с владельцем данных. Нельзя автоматически выставлять `approved`.

Интеграция: backend хранит подтверждения метрик и запускает генерацию после обновления технического каталога; LLM может подставлять только утверждённые и доступные KPI. Для новых датасетов никаких искусственно «подходящих» бизнес-формул не предлагается. SQL здесь не исполняется, реальные значения не рассчитываются. В BI-32 ещё предстоит согласование бизнес-правил и сквозной тест с FastAPI/LLM.
