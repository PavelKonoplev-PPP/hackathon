# Проверка аномалий и сегментов

Этот инструмент помогает проверить аналитические расчёты на произвольных таблицах PostgreSQL без изменения исходных CSV. Данные остаются в \`raw\` и читаются под ролью \`bi_reader\`.

## Аномалии: межквартильный размах

Для каждой комбинации из 1–3 признаков считаются Q1 (25-й перцентиль), Q3 (75-й перцентиль), межквартильный размах \`IQR = Q3 − Q1\`. Значение помечается статистическим выбросом, если оно строго ниже \`Q1 − 1.5 × IQR\` или выше \`Q3 + 1.5 × IQR\`.

Метод Тьюки определяет **статистически необычные значения**, не ошибки данных и не доказательство мошенничества. Суммы, возвраты и отрицательные значения не удаляются автоматически.

- Некорректные числа и пустые поля игнорируются в квартилях, но учитываются в отдельном счётчике «Пропусков или ошибок».
- Полностью пустые признаки группировки не образуют самостоятельные группы; в отчёт попадают группы с непустыми значениями всех выбранных признаков.
- Для групп с числом корректных значений ниже \`--min-sample\` выводится \`insufficient_sample\`, количество выбросов — \`NULL\`, а не ложный ноль.
- При \`IQR=0\` любое отличное от Q1 значение формально попадает за нулевые границы. Это математическое свойство метода; для очень дискретных метрик метод может быть неподходящим.

Пример для существующей таблицы «Доставка»:

\`\`\`bash
python db/segment_quality.py outliers \
  --table data_04_Доставка \
  --segment "Способ доставки" \
  --segment "Перевозчик" \
  --metric "Стоимость доставки, руб." \
  --min-sample 100 --limit 30
\`\`\`

## Сравнение сегментов по двум периодам

Для 1–3 признаков выводятся число записей, число корректных значений, пропуски, сумма, среднее, абсолютное и процентное изменение среднего между двумя непересекающимися периодами \`[start, end)\`.

Если в любом периоде меньше \`--min-sample\` корректных значений, среднее и изменение для этого периода не подтверждаются. При нулевом среднем в базовом периоде процентное изменение равно \`NULL\`, а не бесконечности.

Например, если в источнике есть колонка даты отправки с названием \`Дата отправки\`:

\`\`\`bash
python db/segment_quality.py compare \
  --table data_04_Доставка \
  --segment "Способ доставки" \
  --segment "Перевозчик" \
  --metric "Стоимость доставки, руб." \
  --date-column "Дата отправки" \
  --date-kind date \
  --first-start 2025-02-01 --first-end 2025-03-01 \
  --second-start 2025-03-01 --second-end 2025-04-01
\`\`\`

Проверяйте названия колонок по фактическому каталогу. Команды приведены как примеры и требуют локальной базы. Формат даты в \`--date-kind\` должен совпадать с проверенным типом данных.
