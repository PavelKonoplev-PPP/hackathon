# Экспертные SQL-проверки перед финалом

\`db/expert_regression.py\` запускает **шесть независимых контрольных SQL** из \`TestCases.md\` для проверки данных, формул и ожидаемых значений. Это не проверка работы языковой модели: если агент не умеет сформулировать SQL, тест эталонного SQL всё равно может пройти.

## Что проверяется

| № | Запрос | Ожидаемый результат |
|---|---|---|
| 1 | Среднедневные покупки лекарств на аптеку, февраль/март 2025 | Препарат 1019, 1.5464 → 2.0153, +30.32%, 40 аптек |
| 2 | Изменение чистой выручки по городам | Калининград, 1 627 110.35 → 2 640 589.14, +62.29% |
| 3 | P90 времени закрытия поддержки | «Доставка заказов», 4515 обращений, 72.49 ч |
| 4 | P95 опоздания среди доставленных отправлений | «Собственная доставка», 3733 отправления, 23.15 ч |
| 5 | Согласованные, неоплаченные заявки на 31.03 | Информационные технологии (ИТ), 4158 заявок, 851 088 269.49 руб. |
| 6 | Успешные цепочки только после повторов | «Очистка временных файлов», 581 из 11 083, 5.24%, 2.32 попытки |

Ожидаемые значения взяты из контрольного отчёта \`TestCases.md\` и должны проверяться на исходном наборе из девяти CSV. Не переносите их автоматически на другую базу.

## Запуск без изменения данных

Используется существующая конфигурация \`POSTGRES_READER_USER=bi_reader\` и \`POSTGRES_READER_PASSWORD\` из локального \`.env\`, с \`SET TRANSACTION READ ONLY\` и ограничением выполнения каждого запроса 60 сек.

Из корня репозитория, после установки \`db/requirements.txt\`:

\`\`\`bash
python db/expert_regression.py --report data/expert-regression.json
\`\`\`

Один сценарий:

\`\`\`bash
python db/expert_regression.py --case expert_01_drug_daily_growth \
  --report data/expert-regression-01.json
\`\`\`

Папка \`data/\` исключена из Git. В отчёте сохраняются дата, статус, ожидаемое и фактическое значение. Статус \`pass\` означает точное совпадение с эталоном после округления в SQL. \`fail\` — расхождение, \`error\` — проблема SQL, подключения или таймаут.

Тесты структуры и сравнения результатов без БД:

\`\`\`bash
python -m unittest discover -s db -p 'test_*.py'
\`\`\`
